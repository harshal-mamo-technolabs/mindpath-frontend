# The Month You Stop Bracing - image brief

12 images. Generate each one and save it in this same folder using the exact filename in its heading - the book references that filename, and a missing file simply hides the figure rather than breaking the page.

Destination: `mindpath-frontend/public/ebook-art/the-month-you-stop-bracing/`

All images share one style, already restated inside every prompt below:

> Calm flat vector illustration, soft blue, pale sand and gentle green, low even light, wide landscape composition, generous negative space, no text and no people.

Every image must be **landscape**, roughly 3:2 - they render as a full-width band inside a page of text. Portrait images will look wrong.
